## What changed in this completion pass

Release tooling now accepts twelve complete source/artifact-bound reports instead of permanently refusing every candidate. It validates known unique check IDs, exact subject, report checksum, confined paths, positive assertions and zero failures/skips; operator attestations are explicitly labelled. Caller booleans and descriptive pass labels grant nothing. Clean-source packaging rechecks the evidence, binds SDK/module packages, SDK/frontend builds and all contract WASM/ABI hashes, and refuses changed bytes under an existing version. It publishes and deploys nothing. See [release qualification](../operations/release-qualification.md).

Core, module manifests/peers, frontend dependencies/locks, public packages and generated help are coordinated at 0.8. Original instruction/content domains and retained Archive decoders stay intact. All READMEs/changelogs and the [0.8 upgrade guide](../operations/upgrade-0.8.md) distinguish development acceptance from public availability. The sixteen task rows and implementation checkboxes are reconciled; external compound checks remain open.

The live Pinata drill found a genuine adapter bug: a nonempty last-row cursor was treated as truncated inventory even when the next page was empty. Bounded pagination now verifies the terminal page, caps complete inventory at ten objects and requests at eleven, and rejects duplicate IDs, loops and mismatched ownership. Regression tests first failed, then passed. Pinata's [official SDK pagination source](https://github.com/PinataCloud/pinata) and [list documentation](https://docs.pinata.cloud/sdk/files/public/list) were checked against the installed 2.5.6 SDK and actual responses. Existing owned synthetic upload recovery and a fresh upload/list/direct-ID/retrieve/unpin/absence drill both passed. No existing user file was removed.

The native purchase fixture now buys 12 MiB for setup: the current runtime exceeded its previous 8 MiB. Native proof output goes to ignored artifacts instead of overwriting a dated historical evidence file. The older 2026-10-08 evidence is preserved.
