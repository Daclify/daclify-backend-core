# Mini-App Promotion and Qualification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:executing-plans` inline. No delegation. Track checkboxes and distinguish preparation from publication.

**Goal:** Promote mini apps clearly on the main website and qualify the complete self-service/privacy/exit journeys as an immutable release candidate.

**Architecture:** Add one multilingual website topic using the existing typed content/render/export pipeline, with prominent homepage/nav entry and frontend links. Consolidate cross-repository fixture, upgrade, recovery, resource and privacy evidence through existing release tooling. Prepare rollout/rollback artifacts without deploying.

**Tech Stack:** Existing static TypeScript site, en/es/pl content, HTML/Markdown/LLM exports, Vitest/Playwright, existing native/provider/release tooling.

**Spec:** [Design](../specs/2026-10-12-self-service-mini-apps-and-account-exit-design.md); [master](2026-10-12-self-service-mini-apps-and-account-exit.md); canonical [release/docs/test policy](2026-10-05-daclify-v2-release-docs-test-policy.md).

## Global Constraints

Honor master constraints. Website stays on `main`; other producer/client repositories use `dev`. Publish only availability demonstrated by the qualified release, not current source version numbers. All en/es/pl pages, navigation, canonical/alternate metadata and Markdown/LLM exports agree. No GDPR-compliant, anonymous, all-harness, fully-erased or database-hosting promises without the relevant evidence.

## Review Focus

1. Homepage says available while a locale/export still says proposed — Q1 route/content checks.
2. A clean builder cannot install artifacts without private workspace access — Q2 clean-machine proof.
3. Native upgrade/backup restore loses pending events, keys or claims — Q2 restore/upgrade tests.
4. Logical deletion is mistaken for disk reclamation/history erasure — Q2 actual measurements/report.
5. Development artifacts are packaged as a clean qualified release — Q3 source/evidence binding.
